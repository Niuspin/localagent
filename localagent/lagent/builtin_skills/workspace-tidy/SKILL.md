# 整理文件夹

1. **只读盘点**：`list_dir`、`glob` 统计各类文件数量、体积、最近修改时间，找出重复文件名和明显的临时文件（`~$*`、`.tmp`、`.bak`）。
2. **先出方案，不动手**：用表格列出“原路径 → 新路径”和“建议删除”，让用户确认（用 `ask_user` 或直接在回复里请示）。批量操作永远先确认。
3. **执行**：用 `make_dir` + `move_path` 归类；删除用 `delete_path`（会进回收站，可撤销）。不要用 `run_command` 的 `rm`/`mv` 代替。
4. **不碰**：`.git`、`node_modules`、配置和密钥类文件、以及用户没提到的子目录。
5. 完成后列出变更摘要，并提醒可在“工作区面板 → 变更”里撤销。
