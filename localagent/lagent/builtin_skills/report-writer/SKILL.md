# 报告撰写

1. **确认受众和用途**（给谁看、要多长）。不清楚就按“一页摘要 + 正文”处理，不要反复追问。
2. **先读材料**：用 `list_dir`/`glob` 找到相关文件，用 `read_file` 读取（docx/xlsx/pdf 也可直接读）。
3. **列提纲再写**：标题 → 摘要（结论先行）→ 背景 → 要点（每点一个小标题）→ 风险/待办 → 附录/来源。
4. **写作要求**：一段一个意思；数字带单位和口径；引用材料时注明出处文件名；不确定的内容明确标“待确认”。
5. **输出**：Word/PDF 用 `write_document`（支持标题、列表、表格）；要 Excel 用 `write_spreadsheet`；要幻灯片用 `write_presentation`。文件名用中文或英文均可，放在工作区的 `output/` 下。
6. 写完后用 `read_file` 回读一遍，检查乱码、表格错位和遗漏。
